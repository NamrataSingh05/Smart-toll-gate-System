# STM32 Smart Toll Gate System

## Overview

A smart toll gate system developed using STM32 microcontroller to automate vehicle authentication and toll collection.

The system uses RFID technology for vehicle identification, an OLED display for status updates, and a GSM module for SMS notifications.

## Features

- RFID-based vehicle authentication
- Automatic toll access control
- OLED display for system status
- GSM-based SMS notifications
- Real-time vehicle verification
- Embedded peripheral interfacing

## Hardware Used

- STM32 Microcontroller
- RFID Reader Module
- GSM Module
- OLED Display
- Power Supply Circuit

## Communication Protocols

- UART (GSM Communication)
- I2C (OLED Interface)

## Working Principle

1. Vehicle approaches the toll gate.
2. RFID tag is scanned.
3. STM32 verifies the vehicle information.
4. OLED displays authentication status.
5. GSM module sends an SMS notification.
6. Toll gate access is granted for authorized vehicles.
